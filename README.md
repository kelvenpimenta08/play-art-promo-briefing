# Briefing Digital — Motorista Série A · Play Art Promo

Formulário responsivo para desktop e celular, organizado em etapas, com revisão e geração local de PDF.

## Publicar na Vercel

1. Crie um repositório **privado** no GitHub e carregue os arquivos desta pasta na raiz.
2. Entre na Vercel, escolha **Add New > Project > Import Git Repository** e selecione o repositório.
3. Em **Framework Preset**, escolha **Other**. Não precisa configurar Build Command, Output Directory ou variáveis de ambiente.
4. Clique em **Deploy**. Depois compartilhe a URL fornecida pela Vercel.

## Como funciona

- Funciona no navegador em telas de celular e computador.
- As respostas ficam somente no navegador do usuário e o PDF é gerado localmente.
- O botão **Compartilhar PDF** usa o recurso de compartilhamento do dispositivo, se disponível. Caso contrário, faz o download do PDF.
- **Não envia respostas automaticamente** à Play Art Promo. Para recebimento automático será necessário backend, serviço de formulário e um destinatário configurado, com consentimento e proteção adequados.
- Não solicitar senhas ou credenciais no formulário.

## Segurança e privacidade

Não cole dados sensíveis. Recomenda-se manter o repositório privado. O site hospedado será publicamente acessível a quem tiver seu link, salvo configuração adicional de proteção na Vercel.
